# Phase 1 Results — Offline detection

Every number below comes from the commands in [Reproduce](#reproduce) and matches `data/phase1_detections.csv`. This is a smoke test of the pipeline on one small synthetic PCAP, not a benchmark; accuracy numbers come in Phase 5.

## Model

Isolation Forest (`n_estimators=200`, `random_state=42`) on `log1p` of the 5 shared features, trained on benign CICIDS2017 Monday flows.

| Item | Value |
|---|---|
| Training file | `MachineLearningCVE/Monday-WorkingHours.pcap_ISCX.csv` |
| Rows read | 529,918 |
| Rows dropped (NaN / infinite / negative in the subset) | 15 |
| Benign rows available | 529,903 |
| Rows trained on (random sample, `random_state=42`) | 50,000 |
| Flag rule | anomaly score > 99th percentile of benign training scores |
| Threshold | 0.6738 |
| Feature order | `flow_duration_s, fwd_packets, bwd_packets, total_bytes, packets_per_s` |

## Sample PCAP

`tests/fixtures/sample.pcap`, generated by `tests/fixtures/make_sample_pcap.py`: 600 packets on 127.0.0.1 forming 71 flows.

| Traffic | Flows | Flagged |
|---|---|---|
| Benign TCP sessions to port 8080 | 20 | 0 |
| SYN port scan, ports 1–50 | 50 | 0 |
| SYN flood, 300 SYNs from one source port to port 80 | 1 | 1 |
| **Total** | **71** | **1** |

## Detection CSV

`data/phase1_detections.csv`:

| timestamp | src_ip | dst_ip | attack_type | score | severity |
|---|---|---|---|---|---|
| 2023-11-14T22:14:20.299Z | 127.0.0.1 | 127.0.0.1 | anomaly | 0.991 | high |

The timestamp is the flood flow's last packet (fixture base time 1,700,000,000 + 60 s + 0.299 s), which identifies it as the SYN flood.

## What this shows

- The pipeline works end to end: PCAP → flows → shared features → model trained on CICIDS2017 → CSV.
- The flood stands out on packet rate and one-directional packet counts.
- The port scan is **not** detected. Each probe is a 2-packet flow, which looks like the many short benign flows in CICIDS2017. Catching scans needs either the supervised model (Phase 5, which has a `PortScan` class) or cross-flow features, which are out of scope. Recorded in [LIMITATIONS.md](LIMITATIONS.md).
- The synthetic benign sessions are 20 near-identical flows, so "0 of 20 benign flagged" says little about the false-positive rate on real traffic. Phase 5 measures that properly.

## Design changes made in this phase (human-approved)

1. TCP flag counts were dropped from the shared feature subset (9 → 5 features). See [DATA_MODEL.md](DATA_MODEL.md#shared-feature-subset).
2. Isolation Forest flags by benign-score percentile instead of `contamination="auto"`.

## Reproduce

Requires `data/raw/cicids2017/MachineLearningCSV.zip` (official UNB download, registration form; 235,102,953 bytes, sha256 `c3f26274b36c837ccf28ffd2dbf4582941c30b3ee70a635c6e5b2f87c4727928`).

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
unzip -o data/raw/cicids2017/MachineLearningCSV.zip 'MachineLearningCVE/Monday-WorkingHours.pcap_ISCX.csv' -d data/raw/cicids2017/
.venv/bin/python backend/ml/train_baseline.py --csv data/raw/cicids2017/MachineLearningCVE/Monday-WorkingHours.pcap_ISCX.csv
.venv/bin/python backend/detect_offline.py --pcap tests/fixtures/sample.pcap --out data/phase1_detections.csv
```
